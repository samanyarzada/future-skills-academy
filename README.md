# Future Skills Academy

Future Skills Academy is a simple educational website designed to introduce learners to digital skills and web development.

The website focuses on learning by creating practical projects and provides a simple learning path for beginners who want to improve their digital and front-end development skills.

## About the Project

The goal of this project is to create a clean and simple landing page for a digital skills learning academy.

The website introduces the learning programme and explains how learners can improve their skills through practical lessons, guided practice, feedback, and real projects.

## Features

- Home section with an introduction to the academy
- About the programme section
- Learning path section
- Navigation links
- Explore the programme button
- Back to top link
- Responsive background image
- Simple and clean layout

## Learning Path

The website presents several areas that learners can practise:

- Building clear page structures with HTML
- Styling pages with CSS
- Creating practical projects for a portfolio
- Improving work through practice with mouse and keyboard

## Technologies Used

- HTML5
- CSS3

## Getting Started

To run the project locally, clone the repository:

```bash
git clone https://github.com/USERNAME/future-skills-academy.git
```

Open the project folder:

```bash
cd future-skills-academy
```

Then open `index.html` in your web browser.
